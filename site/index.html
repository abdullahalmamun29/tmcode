tmcode

A lightweight code editor that lives in your terminal. Open a folder, write code in any language, and run it, without leaving the terminal.

Install

curl -fsSL https://abdullahalmamun29.github.io/tmcode/install.sh | sh
powershell -ExecutionPolicy Bypass -c "irm https://abdullahalmamun29.github.io/tmcode/install.ps1 | iex"
pipx install tmcode

No Python needed for the one-line installers. Then open a new terminal and run tmcode inside a project folder. TmCode tells you when an update is out.

What you get

  • Any language. Colors for hundreds of languages, and F5 runs about 50 of them: Python, C, C++, JavaScript, Go, Rust, Java, Kotlin, Swift, C#, and more.
  • Web files. F5 on an HTML or CSS file opens the page in your browser.
  • A real terminal when you need it. Shift+F5 runs your program full-screen; Ctrl+T drops you into your own shell.
  • Editing that keeps up. Auto-closing brackets, auto-indent, suggestions, find & replace, go to line, format on save.
  • Your layout. Tabs, split view, and a file tree and output panel you can drag to resize or hide.
  • Small and fast. About 17 MB, starts in a moment, works over SSH.
